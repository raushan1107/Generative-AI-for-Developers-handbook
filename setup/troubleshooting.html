Troubleshooting, Cost Guardrails and Clean-up

Keep this page open in a tab. It covers the errors everyone hits on the first day, how to make sure a runaway loop can't surprise you with a bill, and how to clean up at the end of the course.

The errors everyone hits once

You seeUsual causeFix
401 Unauthorized / invalid keyWrong key, a key from another resource, or a stray space or quote in .envCopy the key again; no quotes, no spaces around =.
404 deployment or model not foundAZURE_OPENAI_DEPLOYMENT isn't your deployment name, or the base URL is missing /openai/v1/Use the exact deployment name (chat) and check the URL ending.
400 Unsupported parameter: temperature / max_tokensYour deployment is a reasoning model, which rejects some sampling parametersExpected in some drills, which explain it. Use max_completion_tokens instead of max_tokens.
429 Too Many RequestsTokens-per-minute limit reachedWait (the SDK retries), or raise the TPM on the deployment.
No quota when deployingNo capacity for that model in your subscription or regionTry another small model or another region.
KeyError: 'AZURE_OPENAI_BASE_URL'.env isn't in the folder you ran Python fromcd genai-labs and run again.
ModuleNotFoundErrorWrong folder, or the virtual environment isn't activeActivate .venv; run from the folder that contains the file.
Connection refused localhost:11434Ollama isn't runningStart the Ollama app, or run ollama serve.
Your AI assistant edits the wrong filesVague prompt or the wrong folder openOpen the right folder; name the files and add "don't change any other files".
Drill 00.5

Debug with your assistant, the right way

~5 minCopilot · Claude Code · Codex

Goal: practise giving an assistant evidence instead of "it doesn't work".

  1. Run

    In .env, change AZURE_OPENAI_DEPLOYMENT=chat to chatt, then run python lab00_hello.py. Copy the full error.

  2. Ask AI 
    Running `python lab00_hello.py` fails with the error below. Using #llm.py and #lab00_hello.py,
explain the most likely cause in two sentences and tell me exactly what to change.
Do not edit any files and do not print or ask for my API key.

<paste the full error here>
    Why this prompt works: it gives the exact command, the exact error and the relevant files, asks for a diagnosis instead of an edit, and protects your secrets.
  3. Verify
    • The assistant points at the deployment name (a 404 "deployment not found").
    • Put chat back; the smoke test passes again.

Cost guardrails

  • Pay per token. Global Standard deployments cost nothing while idle. On a mini-class model, all of Part I usually costs a few dollars at most. Check your model's current price.
  • Set a budget alert. In the Azure portal, search Cost Management › Budgets › Add, scope it to rg-genai-labs, and alert at, say, $20. It's free and catches mistakes.
  • Cap throughput. The low tokens-per-minute limit on chat is your seatbelt against a runaway loop.
  • Keep it for the whole course. Later modules add an embeddings deployment and more services to the same resource group.

Clean-up at the end of the course

$ az group delete --name rg-genai-labs --yes --no-wait

Also revoke OpenAI or Anthropic keys you no longer need, and run ollama rm llama3.2 to free disk space.
