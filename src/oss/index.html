How to use this guide

  • One lab per Part, about three hours each. Your trainer demonstrates the Part's topics; then you work through the lab on your own computer. Each lab is a sequence of exercises, each exercise a sequence of tasks, each task a list of numbered steps.
  • Do Lab 0 first, once. It installs and checks everything: Python, VS Code, Ollama and the models. Allow 30 to 60 minutes, most of it downloading.
  • Every step tells you what to expect. Commands are in dark boxes; expected output follows. Output from a language model will differ from the examples in wording, which is normal. Numbers, file names and error messages should match.
  • Checkpoints at the end of each exercise tell you what you should have before moving on. If something doesn't match, use the troubleshooting table in that lab.
  • The code is provided. You type or paste each file as you go, so you see how it's built. If you fall behind, download oss-labs-complete.zip with every lab file (you still create your own .env, as in Lab 0).

Why open-source models?

Open models on Ollama (this guide)Hosted APIs (the main handbook)
CostFree; runs on your computerPay per token; needs a subscription or key
PrivacyWith local Ollama settings, model requests stay on your machineData goes to the configured provider (under its terms)
SpeedDepends on your hardware; seconds to a minute per answer on a laptopFast and consistent
QualityGood for learning; small models make more mistakes, which is instructiveStronger models, better instruction following
CodeThe same OpenAI-compatible Python codeThe same code, different URL, key and model

Ollama exposes an OpenAI-compatible API at http://localhost:11434/v1, so the code you write here works with Azure OpenAI, OpenAI or any compatible provider by changing three settings. What you learn transfers directly.

Allow disk space for the models you choose; download sizes and hardware requirements can change by model and quantization. You also need a supported operating system and an internet connection for downloads. If your computer is too slow, Lab 0 explains an alternative: a hosted open-model provider, which sends requests to that provider and may require a key or incur charges.

For trainers

Ask learners to complete Lab 0 before the course begins; downloads on a shared network can take time. Each lab maps to one Part of the handbook and assumes the Part was demonstrated first. The labs use the same fictional RR Finance Bank scenario and data as the handbook: a retail bank building a customer-support assistant.
