Every lab mixes six kinds of steps

Sometimes you paste code. Sometimes you prompt an AI assistant. Sometimes you write the prompt yourself. You always verify.

Run
Copy the code we give you, run it, read the output. The fastest way to see a concept work.
Ask AI
Paste a ready-made prompt into GitHub Copilot, Claude Code or Codex in VS Code. We explain why the prompt works and what you should get.
Your prompt
Write the prompt yourself from a template and a hint, then compare with ours. This is where prompt engineering becomes a habit.
Verify
Tests, commands and checklists that prove the result is right. AI-written code is a draft until you've verified it.
No-code
Try the idea in the Foundry playground, ChatGPT or Claude.ai first. Great for building intuition before coding.
Think
Short design exercises: pick the pattern, choose the model, spot the trap. Answers are hidden until you've committed to yours.
