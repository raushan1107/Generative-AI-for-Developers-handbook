Python and the lab folder

You need Python 3.11 or newer and VS Code with the Python extension. Create the drills folder and a virtual environment:

Windows (PowerShell) 
PS> mkdir genai-labs; cd genai-labs
PS> python -m venv .venv
PS> .venv\Scripts\Activate.ps1
macOS / Linux 
$ mkdir genai-labs && cd genai-labs
$ python3 -m venv .venv
$ source .venv/bin/activate

Create requirements.txt and install it:



$ pip install -r requirements.txt


Then open the folder in VS Code: code .



Your AI coding assistant


Pick one. Every Ask AI and Your prompt step works with all three. Follow the vendor's current install instructions; the essentials are below.



  
OPTION 1
GitHub Copilot
Install the GitHub Copilot extension and sign in with GitHub. Open the Chat view (Ctrl+Alt+I on Windows/Linux, ⌃+⌘+I on macOS) and switch to Agent mode, so it can create and edit files and run commands with your approval. Add files to the context with #.

  
OPTION 2
Claude Code
Install the Claude Code extension for VS Code, or run claude in the integrated terminal from your project folder. It reads your files, proposes edits and runs commands with your permission. Mention files with @.

  
OPTION 3
OpenAI Codex
Install the Codex IDE extension, or use the codex CLI in the integrated terminal from your project folder. Sign in with your ChatGPT or OpenAI account. It can edit files and run commands in the workspace with your approval.





  
Tool names and modes change

  
All three tools ship new versions every few weeks, so menu names and shortcuts change. What matters is the same everywhere: the assistant must be able to see your folder, propose file edits and run commands with your approval.

Optional tracks: OpenAI, Claude, Ollama



  

    
OpenAI API

    
Create a key at platform.openai.com and add a little credit. In .env: LLM_PROVIDER=openai, OPENAI_API_KEY=…, OPENAI_MODEL=gpt-5.4-mini. A ChatGPT subscription is not an API key; they're billed separately.

  

  

    
Anthropic Claude API

    
Create a key at platform.claude.com and add credit. In .env: ANTHROPIC_API_KEY=…. Claude uses its own SDK, so the Open alternative boxes use claude_llm.py. Claude models are also available inside Microsoft Foundry.

  




Ollama: a free model on your laptop


Install from ollama.com, then pull a small model and test it:


$ ollama pull llama3.2
$ ollama run llama3.2 "Explain an API in one sentence."


Set LLM_PROVIDER=ollama to run the drills locally. Ollama exposes an OpenAI-compatible endpoint at http://localhost:11434/v1. Small local models are noticeably weaker, which is itself a lesson in Module 01.
