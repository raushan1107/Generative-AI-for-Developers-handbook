The .env file

In plain words

Your code never contains a key. Keys and settings live in .env, which stays on your machine (your .gitignore from Drill 00.3 keeps it out of Git), and python-dotenv loads it when a script starts.

Copy this as .env in genai-labs and fill in your values:




  
Common trap

  
Someone always pushes .env to a public repo "just for a minute". Automated scanners find leaked keys within minutes. If it happens, regenerate the key in the portal immediately; deleting the commit isn't enough.





The shared helpers


This is the only file that knows which provider you use. Every drill just does from llm import get_client, MODEL.




Claude gets its own helper because it uses Anthropic's SDK. FALLBACK lets the API retry a request on another Claude model automatically if a safety check declines it.





  
Traditional developer view
