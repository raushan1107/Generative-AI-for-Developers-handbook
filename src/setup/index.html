Four tracks, one set of labs

In every batch I teach, some people have a company Azure subscription, some have a personal one, and one or two have nothing but a laptop and a browser. All of them should be able to do every lab.

MAIN TRACK

Azure OpenAI in Microsoft Foundry

What most enterprises use, and what later modules build on (AI Search, Content Safety, API Management, Container Apps). Pay per token; nothing while idle.

DIRECT APIS

OpenAI or Claude

Direct provider APIs. OpenAI uses the same code; Claude has its own SDK, shown in every Open alternative box. Needs an API key with a little credit.

LOCAL AND FREE

Ollama

An open-weight model running on your laptop. Slower and less capable, but free, private and offline. 8 GB+ RAM recommended.

NO-CODE

Chat apps

The Foundry playground, ChatGPT or Claude.ai. Many concept drills start here because the feedback loop is instant.

Your setup path

  1. Azure: Foundry and a model (~10 min). Create a Foundry resource and deploy a chat model named chat, through the portal or by asking your AI assistant to write the Azure CLI script. Skip if you're on another track.
  2. Workstation and AI assistant (~10 min). Python, VS Code, a virtual environment, and GitHub Copilot, Claude Code or Codex ready in VS Code.
  3. Helpers and smoke test (~5 min). The .env file, the shared llm.py helper, and a one-line test that proves the pipe works.
  4. Troubleshooting and cost. Keep it open in a tab; it covers the errors everyone hits once, budget alerts and clean-up.

You're ready when…

  • python lab00_hello.py prints a greeting and a token count.
  • Your AI coding assistant can see and edit files in your genai-labs folder.
  • Your .env is listed in .gitignore.
  • (Azure) A budget alert is set on your resource group.
