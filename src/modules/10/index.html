In the real world

Microsoft's Azure OpenAI data, privacy and security documentation describes how data submitted to Azure-sold models is processed and stored. Teams must still review their service configuration, contractual terms and data-protection obligations rather than assuming a model provider decides the application's retention policy. See Microsoft Learn: data, privacy and security.

In finance

RR Finance Assist must not ask for a PIN, password or one-time code, and a model-generated request cannot authorize a transfer or dispute. Keep customer identity in the authenticated server context, minimize data sent to the model, and make sensitive actions require a human decision.

GenAI developer view
