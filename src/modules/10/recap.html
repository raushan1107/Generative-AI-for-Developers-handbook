Security and responsible AI review.

1. What should happen if a retrieved article tells the model to call a write tool?

Treat it as untrusted content. Application code still verifies identity, permissions, policy and approval before any write.

2. What does the M10 masker guarantee?

Only that its tested labeled patterns are replaced in those tests. It does not guarantee complete PII detection or regulatory compliance.

3. Why is a prompt instruction not an authorization check?

The model can misunderstand or be influenced by untrusted content. Authorization must be enforced by trusted server-side code using authenticated identity.

4. What is next?

Module 11 measures cost and latency, using the evaluation practices from Module 09 to ensure optimization does not degrade critical behavior.

Remember

Minimize sensitive data, constrain model authority, test safety across relevant users and provide human escalation for consequential cases.
