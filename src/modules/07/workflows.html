Learn

Fixed paths where you can, model choices where you must.

Definition

An agent workflow (or LLM workflow) is a system in which models and tools are combined along paths defined in code. Common patterns: prompt chaining (one step's output feeds the next), routing (classify, then send to a specialised handler), parallelisation (independent steps at once), orchestrator and workers (a model splits a task, workers do the parts), and evaluator and optimiser (one model drafts, another checks, repeat). In an agent, by contrast, the model decides the path.

In plain words

If you can draw the flowchart, write it in code and let the model fill in the boxes that need language or judgement. Use a free-roaming agent only when you can't draw it.

Imagine this

A hospital's triage desk. The nurse decides which department you go to (routing); each department has its own protocol (a fixed chain); test results come back in parallel; a senior doctor reviews the junior's plan (evaluator). Only an unusual case gets a specialist who works it out from scratch: the agent.

Workflow or agent?

QuestionIf yes
Can you list the steps for this kind of request in advance?Workflow
Do the steps depend on what earlier steps discover, in ways you can't enumerate?Agent
Must every run be predictable, auditable, cheap and fast?Workflow, or an agent with tight limits
Is a wrong step costly and hard to undo?Workflow with approvals; agent only for read steps
Do requests vary widely, combining several needs in one message?Router + agent for the mixed ones
In the real world
In finance

Most banking processes are better as workflows than as free agents: card replacement, dispute intake and address changes follow fixed steps with regulatory checkpoints. A model routes the request and writes the reply; code runs the steps. Agents earn their place where the path really varies, and even then they work inside guardrails a workflow provides.

Many "AI agents" in production are workflows with one or two model decisions: a router that classifies tickets, fixed handlers per category, a model that drafts the reply, and an evaluator check before sending. Teams start there because it's testable and cheap, then add agentic loops only for the requests the router labels "complex". Microsoft's Agent Framework and similar libraries support both graph-style workflows and free-form agents for this reason.

Traditional developer view

"Hard-code every path."

GenAI developer view

"Hard-code the paths I can predict, use a model for routing and language, and give a model the steering wheel only where the path truly varies, measuring the cost of that freedom in calls and failures."

Common trap

Building an agent for a flowchart. "Check lab status and tell the customer" is two fixed steps; an agent may take four calls, wander, or skip the check. Use the simplest pattern that works, and measure.

Interview cue

"I distinguish workflows, where code defines the path (chaining, routing, parallel, orchestrator-workers, evaluator-optimiser), from agents, where the model chooses it. I default to workflows for predictable tasks and use agents for open-ended ones, with the same tools underneath."

Workflows.



  
1. Name the five workflow patterns and one use of each.
Chaining (draft then polish), routing (send each ticket category to its handler), parallel (fetch lab and voucher status at once), orchestrator-workers (split a long research task), evaluator-optimiser (check a reply against rules and revise).

  
2. Is Milestone 6's /api/ask a workflow or an agent?
A workflow: a fixed chain (retrieve, then maybe generate, then check). The chat's search_help tool is agentic: the model decides when and how often to search.

  
3. Your router sends 85% of requests to fixed handlers and 15% to an agent. Why is that a good design?
Most traffic gets the cheap, fast, predictable path; the agent's extra cost and risk are spent only where flexibility is needed, and both share the same tools and guard rails.




Takeaway
If you can draw the flowchart, build a workflow. Give the model the steering wheel only where the path really varies.
