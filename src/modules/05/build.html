Plan

From matching words to matching meaning.

RR Finance Bank· the brief for milestone 5

Customers describe what they want in their own words, and the catalogue tool misses half of it. The support team also wants a search over the ten help-centre articles, both for their own use and as the base for grounded answers next month. Constraints: it must run on a laptop for development, on Azure AI Search in production, and keep working (with plain keyword search) if the embedding service has a bad day.

  3. Ask AI
    The index builder
    
        
    Create scripts/build_index.py (and an empty scripts/__init__.py) for this project, runnable as
python -m scripts.build_index from the project folder.

- If SEARCH_BACKEND (app.config) is "local": LocalIndex.build(get_client()) from #file:app/search.py,
  save it, and print how many course and help documents, the vector dimensions and EMBED_MODEL.
- If it's "azure": create or update an Azure AI Search index named AZURE_SEARCH_INDEX with fields
  id (key), kind/level/format (filterable strings), title and text (searchable; text uses the
  en.microsoft analyzer), source, price_usd (filterable, sortable Int32) and contentVector
  (Collection(Single), dimensions from the embeddings, HNSW profile "vprofile"); then
  merge_or_upload the documents from load_documents() with their vectors and print how many succeeded.
- Import the Azure SDK only inside the Azure branch, so local users don't need it configured.
- Print the elapsed time. No other files.
    
        
    Why this prompt works: it reuses the functions that already exist instead of letting the assistant reinvent chunking or embedding, spells out the index schema field by field (filterable versus searchable is the decision that matters), and asks for lazy Azure imports so the local path stays simple.

  5. Run
    Tests with a fake embedding model
    
        
    Search code needs embeddings, but tests shouldn't call a model. FakeEmbeddings hashes words into a 256-dimension vector: texts that share words get similar vectors. It can't understand meaning, but it's deterministic, which is perfect for testing the plumbing (filters, ranking, save/load, fallbacks).
