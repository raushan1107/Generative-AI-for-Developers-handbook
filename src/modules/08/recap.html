Check

Architecture review.

1. Where should customer ownership checks live?

In the application workflow, using verified identity and the bank's system of record. A gateway can enforce shared access controls but does not know the business relationship.

2. What is the primary purpose of a session TTL?

To bound how long persisted session data remains available. It must align with product needs, legal retention policy and secure deletion requirements.

3. What makes a trace useful without copying sensitive content?

A correlation ID, span relationships, timestamps, status and approved low-risk attributes. Do not attach full prompts, tokens, credentials or customer identifiers by default.

4. What is the next module?

Module 09 builds a representative evaluation set and release gates; its metrics build on the citation limitations in Module 06.

Remember

Gateways control access to model services; application code controls user-facing business outcomes. Treat session data and telemetry as sensitive design surfaces.
