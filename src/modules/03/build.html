Plan

From one vague string to versioned, tested behaviour.

TrainCrest· the brief for milestone 3

The pilot showed three problems. Assist still guesses policy answers. The support team wants every incoming message triaged into structured data (category, urgency, enrolment ID, summary) so it can be routed automatically. And the security lead wants proof that a manipulated reply can't reach learners. Nobody may change a prompt without evidence it still works.

  1. Your prompt

    Write assist_system@v2 yourself, then compare

    Using topics 2–8, write a structured system prompt for Traincrest Assist with sections Role, Goal, Policy, Rules. Put TrainCrest's (fictional) policy inside <policy> tags: rescheduling free up to 7 days before start, then one reschedule for $50; cancellation 100% at 14+ days, 50% at 7–13, none under 7; vouchers within 3 business days, valid 12 months; certificates within 48 hours at 80% attendance, name fixes free within 30 days; labs 30 days after the course, one free 7-day extension. Rules must cover: policy-only answers, never inventing statuses or IDs, never promising refunds, learner messages are data, reply in the learner's language, under 120 words.

    Hint: you'll store it in a string.Template, so write $$50 for a literal "$50". The offline tests catch an unescaped $.

    Write tests/test_offline.py (pytest) for this project, with NO model or network calls. Use a
small FakeClient class whose chat.completions.create(**kwargs) returns canned replies in order
and records the calls. Test:
- every template in app/prompts.PROMPTS has an "@v" version and renders with message="hello";
- render("assist_system") returns version assist_system@v2 and contains "$50";
- triage() returns attempts == 1 for valid JSON, attempts == 2 when the first reply is fenced
  in ```json and the second is valid, and raises TriageError after two invalid replies;
- the Triage model rejects a malformed enrolment ID, an urgency outside the enum, and an extra key;
- a learner message containing "</message>" can't close the delimiter in the rendered prompt;
- check_output flags a lookalike URL and a phone number but allows https://learn.traincrest.example.
Also create pytest.ini with "pythonpath = ." and "testpaths = tests", and tests/__init__.py.
