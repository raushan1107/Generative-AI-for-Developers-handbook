Plan

What v0.1 does, and the shape of the project.

TrainCrest· the brief for milestone 1

Leadership wants to see an AI assistant answer learner questions before investing further. Build the smallest real thing: a command-line app where a support agent types a learner's question and sees the model's answer, the time it took and the tokens it used. It must be a proper project, ready to grow, not a throwaway script.

Target structure after this milestone 
traincrest-assist/
├── .env                 your settings (never committed)
├── .env.example         the settings template (committed)
├── .gitignore
├── requirements.txt
├── app/
│   ├── __init__.py
│   ├── config.py        reads .env
│   └── llm.py           the only place that knows how to reach the model
└── cli.py               Traincrest Assist v0.1

~30 minAzure OpenAIPython · AI assistant

Goal: the Module 01 hands-on exercise: an application that sends a prompt to an LLM and displays the generated response, built as the first version of a real project.

  1. Your prompt

    Scaffold the project with your AI assistant

    Create an empty folder traincrest-assist next to genai-labs, open it in VS Code, and ask your assistant to scaffold it. Write the prompt from the template:

    Goal:        scaffold a Python project called …
Context:     empty folder; Python 3.11+; I'll write the main code myself
Constraints: create these files/folders …; requirements …; .gitignore must …;
             .env.example with these keys …; do NOT create a real .env or any API logic
Done when:   I can create a venv and pip install -r requirements.txt without errors

    Hint: list the exact tree from the Plan section, the two requirements (openai, python-dotenv), the .env.example keys from your drills' .env (with placeholder values only) and the commands to create and activate a venv.

    Compare with my prompt
    Scaffold a Python 3.11+ project in this empty folder for "Traincrest Assist", an AI learner-support
assistant. Create only:
- requirements.txt with: openai, python-dotenv
- .gitignore ignoring .env, .venv/, __pycache__/, *.log
- .env.example with placeholder values (no real secrets) for: LLM_PROVIDER=azure,
  AZURE_OPENAI_BASE_URL, AZURE_OPENAI_API_KEY, AZURE_OPENAI_DEPLOYMENT=chat, OPENAI_API_KEY,
  OPENAI_MODEL=gpt-5.4-mini, OLLAMA_MODEL=llama3.2
- app/__init__.py with a one-line docstring
Do not create .env, config.py, llm.py or cli.py; I'll write those. Finally, tell me the
commands to create and activate a virtual environment on Windows PowerShell and install
the requirements.

    Then create the venv, install, and copy your working .env from genai-labs:

    $ python -m venv .venv
$ .venv\Scripts\Activate.ps1          # macOS/Linux: source .venv/bin/activate
$ pip install -r requirements.txt
$ copy ..\genai-labs\.env .env          # macOS/Linux: cp ../genai-labs/.env .env
