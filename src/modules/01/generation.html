Learn

A loop of educated guesses.

Definition

LLMs generate text autoregressively: at each step the model computes a probability distribution over its vocabulary for the next token, a decoding strategy selects one token from that distribution, the token is appended to the input, and the process repeats until a stop condition is reached.

In plain words

The model writes one token at a time. Each step, every possible next token gets a score ("Jupiter: 96%, Saturn: 2%…"); one is picked, added to the text, and the model goes again with the slightly longer text. That's why answers appear word by word: you're watching the loop run.

Temperature: how adventurous the pick is

The model produces raw scores (logits); softmax turns them into probabilities. Temperature divides the scores before softmax. Low temperature sharpens the distribution so the top choice almost always wins; high temperature flattens it so long shots get a real chance. It changes variety, never knowledge.

Imagine this

A cautious friend and an adventurous friend order from the same menu. The cautious one (low temperature) orders the bestseller every time. The adventurous one (high temperature) sometimes picks the weird special. Same menu, same kitchen. Neither knows more about food.

Why models hallucinate

The model is trained to produce likely text, not true text. Usually they overlap. When the model lacks the fact (TrainCrest's actual voucher policy, last week's price, a learner's enrolment), it still produces the most likely-sounding text, fluently and confidently.

Imagine this

A student in an oral exam who didn't study chapter 7 doesn't stay silent. They give a confident, well-structured answer built from everything that sounds related. Sometimes it's even right. The cure is the same as for the student: hand them the textbook page (grounding, Module 06) and let them say "I don't know" (prompting, Module 03).

In the real world

Press "regenerate" in ChatGPT or Claude.ai and you get a different answer: that's sampling. Watch the answer appear word by word: that's the loop, streamed. Products that must be consistent (extracting invoice fields, routing tickets) constrain the output format and validate it, rather than hoping sampling behaves.

Traditional developer view

"If the output is wrong, the model is buggy. Find a better model."

GenAI developer view

"Wrong-but-fluent is the expected failure mode of next-token prediction. I reduce it by design: give facts, constrain output, allow abstaining, and evaluate."

Interview cue

"Why do LLMs hallucinate?" "They're optimised to generate plausible continuations, not to verify facts. When the needed information isn't in the context or training data, the most plausible text can be false." Then name two mitigations: grounding with retrieved data, and allowing the model to abstain.

Check
Explain it in one sentence each.



  
1. Does setting temperature to 0 make the model correct?
No. It makes the top choice win more consistently. If the top choice is a hallucination, you'll get the same wrong answer reliably.

  
2. Why can a model state a wrong refund policy so confidently?
Because it produces the most plausible continuation, and confidence is just fluent text. Without the real policy in its context, a common policy from training data looks most likely.




Takeaway
Generation is sampling from probabilities. Design so that the likely answer is also the right one: give facts, constrain, verify.
