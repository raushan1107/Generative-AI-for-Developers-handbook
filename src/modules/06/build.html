Plan

From a policy in the prompt to policies in documents.

RR Finance Bank· the brief for milestone 6

The support team updates card, payment and dispute guidance as policies change. If those rules are copied into a system prompt, every update requires a prompt change and redeployment. The brief: answer policy questions from RR Finance Bank's help centre, show customers where each answer comes from, say clearly when the help centre doesn't cover something, and offer a search box on the help-centre site that uses the same engine. Constraints: no policy amounts in prompts, nothing shown as a source that the answer didn't use, and the chat must keep working if search is down.

Milestone 6

Help-centre RAG with checked citations

~75 minAzure OpenAIFastAPI · numpy · pytest

Goal: extend RR Finance Assist with help-centre retrieval. The prompts instruct it to answer from the bank's sources and cite claims; code verifies that cited numbers refer to retrieved sections, but does not prove that a citation supports a claim. The same retrieval pipeline is exposed as POST /api/ask.

  6. Ask AI
    Check citations in the chat service
    
        
    In #file:app/chat.py, ChatService.stream():
1. Create the per-turn context as {"customer_id": customer_id, "sources": []}.
2. After the tool loop, before check_output, run
   reply, cited, unknown = check_citations(full_reply, context["sources"]) from #file:app/rag.py.
   If unknown is not empty, yield {"type": "replace", "text": reply} and log a warning event
   "unknown_citations" with the numbers.
3. Add "sources": [public(s) for s in cited] to the done event, or [] if the output guard flagged
   the reply.
Keep everything else as it is. Then run pytest -q.
    
        
    Why this prompt works: it gives the exact order (citations before the output guard, so a replaced reply is what gets guarded and saved), reuses the existing replace event instead of inventing a new one, and names the functions to import, so the change stays small and reviewable.

    About small local models
    
          
    With llama3.2 (3B), answers are usually right but citations are often missing, and in multi-turn chat the model sometimes writes a tool call as plain text instead of calling the tool. That's the model, not your code: the tests prove the plumbing. Use your Azure chat deployment, or a larger local model such as qwen2.5:7b, to see reliable citations.
