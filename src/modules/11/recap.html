Performance and cost review.

1. Is prompt caching the same as reusing a previous response?

No. Provider prompt caching can reuse eligible prefix processing; application response caching returns a stored result and has additional freshness and data-isolation risks.

2. Why measure p95 latency?

It shows a slow tail experienced by a portion of requests, which an average can hide. Include retrieval, queue wait, retries and model steps.

3. Which tasks are candidates for batch processing?

Tasks that tolerate asynchronous completion, such as a nightly evaluation or bulk analysis. Time-sensitive customer events need a monitored interactive path.

Module 12 turns the evaluation and operational budgets into deployment checks, monitoring and incident procedures.
