1. Which versions belong in a release record?

Application image, model deployment, prompt, tool/schema configuration, evaluation dataset and the approved rollback target.

2. What is the difference between operational and quality monitoring?

Operational monitoring tracks service health such as errors and latency. Quality monitoring evaluates outputs and tasks, such as groundedness, fraud recall and escalation behavior.

3. What does an incident runbook need?

Detection criteria, an accountable owner, containment steps, a customer-safe fallback, communication, recovery/rollback and a post-incident review.

4. Is RR Finance Assist deployed to Azure by this handbook module?

No. The milestone includes local preflight code and operating guidance. Provisioning and deploying Azure resources are separate, explicitly approved activities.

Course takeaway

GenAI applications are software systems with nondeterministic components. Build clear controls, test representative behavior, monitor quality and keep humans accountable for consequential decisions.
