# Exam vouchers

Many certification courses, such as AZ-900, AZ-104 and AI-102, include one exam voucher.

## When you receive it

Your voucher code is emailed within 3 business days after you complete the course. Completion means attending at least 80% of the live sessions, or finishing all modules of a self-paced course.

## How long it is valid

A voucher is valid for 12 months from the date it is issued. It cannot be extended, so book your exam well before it expires.

## Using your voucher

Enter the code when you book the exam with the exam provider. If the provider says the code is invalid, check for spaces at the start or end, then contact support with a screenshot.

## Lost voucher

Search your email for "TrainCrest voucher". If you still can't find it, Traincrest Assist can check the voucher status of your enrolment and resend it.
