Part III Concept Map: Ground It and Let It Act

Part III gives a model access to relevant information and, in controlled cases, application tools. RAG retrieves source material before generation; an agent can coordinate multiple steps. In both cases the application still owns access controls, validation and the decision to execute consequential actions.

What is RAG, and why use it?Retrieval-Augmented Generation supplies selected external information to a model at answer time.
Definition
Retrieval-Augmented Generation supplies selected external information to a model at answer time.
Example
Search current help articles for a dispute deadline, then provide relevant passages to the model.
In finance
RAG can ground a customer-support draft in current bank policy, but the cited policy still needs verification.
Where it's used
Question answering over documents that change or are not in the model's training data.
Keep in mind
RAG can improve access to evidence; it does not guarantee that retrieval or generation is correct.

What is an AI agent? Agent vs chatbotAn agent uses a model to select steps or tools toward a task, while application code runs tools and enforces constraints.
Definition
An agent uses a model to select steps or tools toward a task, while application code runs tools and enforces constraints.
Example
An assistant can look up a customer's card status and request a freeze through a separate approval step.
In finance
A bank agent should not be allowed to move money merely because a model generated a tool call.
Where it's used
Multi-step workflows where tool access adds value beyond a single response.
Keep in mind
More autonomy adds complexity and risk; use the least autonomy that solves the task.
