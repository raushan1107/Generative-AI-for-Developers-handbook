Zero-Shot Prompting

Zero-shot means instructions only, no examples. Modern models are good enough that it works for most common tasks, so it's always your first try. But 'works' needs a number: you'll have your AI assistant generate a test set, verify it, and measure a zero-shot baseline you'll try to beat on the next page.

1

Learn

Always try the simplest prompt first, and measure it.

Definition

Zero-shot prompting asks the model to perform a task from instructions alone, without worked examples, relying on what it learned in pre-training and instruction tuning.

In plain words

Describe the task and let the model do it, with no demonstrations. Try this first; add examples only when it isn't consistent enough.

Classify the TrainCrest learner-support ticket into exactly one category: scheduling, billing,
exam_voucher, certificate, lab_access, account, other. Reply with the category only, in lowercase.

Ticket: "I was charged twice for the AZ-305 course."
WhatInstructions only, no examples.
WhyShortest, cheapest prompt; easiest to maintain.
WhenCommon tasks with obvious categories and formats. Your default first attempt.
Where zero-shot struggles

Company-specific conventions ("is a refund request billing or scheduling?"), unusual formats, slang and mixed languages, and borderline cases. In all of these the model has to guess your convention. Examples fix that (next topic).

In the real world

Before any prompt work, good teams assemble a test set: real (anonymised) or synthetic inputs with the expected answers. They measure the simple zero-shot prompt first to get a baseline, then every change is a measured improvement or it's reverted. Generating synthetic test data with an LLM is now standard practice, with human review of the labels.

Interview cue

"I start zero-shot to get a baseline on a labelled test set, then add examples or structure only if the numbers say it's needed."

Do

Generate a test set, verify it, then measure the baseline.

Make them realistic and varied (5-25 words), with 2-3 tickets in Spanish, French or German.

  2. Verify

    Check the data with code, then with your eyes

    """Drill 03.4: verify an AI-generated test set before you trust it."""
import json
import sys
from collections import Counter
from pathlib import Path

from tickets import CATEGORIES, TEST_TICKETS

path = Path(sys.argv[1] if len(sys.argv) > 1 else "data/eval_tickets.json")
rows = json.loads(path.read_text(encoding="utf-8"))
problems = []

for i, row in enumerate(rows):
    if set(row) != {"text", "label"}:
        problems.append(f"row {i}: keys should be text and label, got {sorted(row)}")
    elif row["label"] not in CATEGORIES:
        problems.append(f"row {i}: unknown label {row['label']!r}")
    elif not row["text"].strip():
        problems.append(f"row {i}: empty text")

texts = [r.get("text", "").strip().lower() for r in rows]
dupes = [t for t, n in Counter(texts).items() if n > 1]
if dupes:
    problems.append(f"{len(dupes)} duplicate texts, e.g. {dupes[0]!r}")

test_texts = {t.lower() for t, _ in TEST_TICKETS}
leaked = [t for t in texts if t in test_texts]
if leaked:
    problems.append(f"{len(leaked)} rows copy the fixed test tickets (that would inflate scores)")

counts = Counter(r.get("label") for r in rows)
print(f"{len(rows)} rows · labels: " + ", ".join(f"{c}={counts.get(c, 0)}" for c in CATEGORIES))
non_english = sum(1 for t in texts if any(ord(ch) > 127 for ch in t))
print(f"rows with non-ASCII text (other languages, accents): {non_english}")
if min(counts.get(c, 0) for c in CATEGORIES) < 3:
    problems.append("every category needs at least 3 examples")

print("\n".join(problems) if problems else "OK: the dataset passes all checks")
sys.exit(1 if problems else 0)

Drill 03.5

Measure the zero-shot baseline

~10 minAzure OpenAIPython

Goal: a number to beat: zero-shot accuracy on the 12 fixed tickets and on your 28-ticket set.

  1. Run 
    """Drills 03.5 and 03.6: zero-shot vs few-shot ticket triage, scored against labels.

  python lab03_05_triage.py --mode zero              # 03.5: zero-shot baseline
  python lab03_05_triage.py --mode few               # 03.6: with examples
  python lab03_05_triage.py --mode both --data data/eval_tickets.json
"""
import argparse
import json
from collections import Counter
from pathlib import Path

from llm import get_client, MODEL
from tickets import CATEGORIES, FEW_SHOT_EXAMPLES, TEST_TICKETS

INSTRUCTIONS = (f"Classify the TrainCrest learner-support ticket into exactly one category: "
                f"{', '.join(CATEGORIES)}. Reply with the category only, in lowercase.")

client = get_client()


def classify(ticket, few_shot):
    messages = [{"role": "system", "content": INSTRUCTIONS}]
    if few_shot:
        for text, label in FEW_SHOT_EXAMPLES:          # examples as user/assistant pairs
            messages += [{"role": "user", "content": text}, {"role": "assistant", "content": label}]
    messages.append({"role": "user", "content": ticket})
    r = client.chat.completions.create(model=MODEL, messages=messages)
    return r.choices[0].message.content.strip().lower(), r.usage.prompt_tokens


def evaluate(dataset, few_shot):
    print("\n===== FEW-SHOT =====" if few_shot else "\n===== ZERO-SHOT =====")
    correct, off_list, tokens, mistakes = 0, 0, 0, Counter()
    for ticket, expected in dataset:
        got, used = classify(ticket, few_shot)
        tokens += used
        correct += got == expected
        off_list += got not in CATEGORIES
        if got != expected:
            mistakes[f"{expected} -> {got}"] += 1
        print(f" {'✓' if got == expected else '✗'} {got:13} (expected {expected:12}) {ticket[:48]}")
    n = len(dataset)
    print(f"Accuracy {correct}/{n} ({correct / n:.0%}) · off-list labels: {off_list} · "
          f"avg input tokens: {tokens // n}")
    if mistakes:
        print("Most common mistakes:", ", ".join(f"{k} x{v}" for k, v in mistakes.most_common(3)))


parser = argparse.ArgumentParser()
parser.add_argument("--mode", choices=["zero", "few", "both"], default="both")
parser.add_argument("--data", help="optional JSON file of {text, label} rows instead of the 12 fixed tickets")
args = parser.parse_args()

data = TEST_TICKETS
if args.data:
    data = [(r["text"], r["label"]) for r in json.loads(Path(args.data).read_text(encoding="utf-8"))]

if args.mode in ("zero", "both"):
    evaluate(data, few_shot=False)
if args.mode in ("few", "both"):
    evaluate(data, few_shot=True)

3

Check

Baselines.

1. Why measure a zero-shot baseline before improving the prompt?

Without a number you can't tell whether a change helped, hurt or did nothing, and you'd keep extra prompt (and cost) that adds no value.

2. Your AI-generated test set passes the checker. Is it trustworthy?

Only partly. The checker verifies shape (keys, labels, counts, leaks). A human must still review whether the labels are correct.

Takeaway

Zero-shot first, measured. Its mistakes tell you exactly what to teach next.
