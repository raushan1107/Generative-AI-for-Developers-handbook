Self-check

1. Traincrest Assist told a learner vouchers are valid for 24 months; TrainCrest's are valid for 12. The code has no bugs. What happened, and what's the fix?

A hallucination: the model produced plausible text without the fact. Fix it by grounding the answer in the real policy (in the prompt now, RAG in Module 06) and telling the model to say when information isn't provided.

2. Why did the Japanese sentence in Drill 01.5 have the fewest characters but the most tokens?

The tokenizer's vocabulary covers Japanese less efficiently, so characters are split into more, smaller tokens. Cost and context use depend on tokens, not characters.

3. Your bigram model (Drill 01.4) and a real LLM do the same core job. What is it, and what makes the LLM so much better?

Both predict a probability for each next token and sample. The LLM uses thousands of tokens of context with attention, learned meaning instead of exact counts, and vast scale.

4. A teammate wants temperature 0 "so the bot stops making things up". Will it?

No. Temperature changes variety, not knowledge. A hallucination at temperature 0 is just a consistent hallucination. Grounding and constraints fix it.

5. Classic ML scored 10/12 in Drill 01.3 and missed the Spanish ticket. Name two ways to fix that.

Add multilingual training examples (an LLM can help generate them), or route non-English or low-confidence tickets to the LLM.

6. What's the difference between what ChatGPT the app does and what the model behind it does?

The model only predicts tokens from its context. The app adds a hidden system prompt, conversation history, often web search and tools, and safety layers. With the API, adding those is your job, starting in Module 02.

Carry this into Module 02

Traincrest Assist v0.1 forgets names, freezes while thinking and would crash on the first network blip. Next you'll treat the LLM as what it really is (a slow, metered, rate-limited HTTPS API that sometimes fails) and call it like a professional: roles and memory, parameters, streaming, errors, retries and cost.
