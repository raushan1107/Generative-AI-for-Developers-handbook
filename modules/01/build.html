Module 01 · Build milestone

Build · Milestone 1: Hello, Traincrest Assist

The progressive project starts here. You'll scaffold a real project with your AI assistant and build version 0.1 of Traincrest Assist: a small application that sends a learner's question to the LLM and displays the answer, with response time and tokens. Then you'll use it to discover exactly what the next modules must fix.

Plan

What v0.1 does, and the shape of the project.

TrainCrest· the brief for milestone 1

Leadership wants to see an AI assistant answer learner questions before investing further. Build the smallest real thing: a command-line app where a support agent types a learner's question and sees the model's answer, the time it took and the tokens it used. It must be a proper project, ready to grow, not a throwaway script.

Before you run this code

Milestones are built in your traincrest-assist folder, on top of the previous milestone, with its virtual environment active. Settings come from .env in that folder; by default it uses a free local model with Ollama (install Ollama, then ollama pull llama3.2), so no key is needed. Azure OpenAI and OpenAI are one-line switches in the same file.

Starting here, or behind? Download the finished project, traincrest-assist-m01.zip. Unzip, copy .env.example to .env, then pip install -r requirements.txt.

.env (default: local Ollama)

  2. Run

    Write the configuration and the model access layer

    """Settings for Traincrest Assist, read from .env so nothing secret lives in code."""
import os

from dotenv import load_dotenv

load_dotenv()

PROVIDER = os.getenv("LLM_PROVIDER", "ollama").lower()   # default: a free local model (Ollama)

# On Azure this is the DEPLOYMENT name; elsewhere it's the model name.
MODEL = {
    "azure": os.getenv("AZURE_OPENAI_DEPLOYMENT", "chat"),
    "openai": os.getenv("OPENAI_MODEL", "gpt-5.4-mini"),
    "ollama": os.getenv("OLLAMA_MODEL", "llama3.2"),
}.get(PROVIDER, "")
    """The only place in Traincrest Assist that knows how to reach the model."""
import os

from openai import OpenAI

from app.config import PROVIDER


def get_client() -> OpenAI:
    if PROVIDER == "azure":
        return OpenAI(base_url=os.environ["AZURE_OPENAI_BASE_URL"], api_key=os.environ["AZURE_OPENAI_API_KEY"])
    if PROVIDER == "openai":
        return OpenAI()
    if PROVIDER == "ollama":
        return OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
    raise ValueError(f"Unknown LLM_PROVIDER: {PROVIDER!r}")
  3. Run

    Write the CLI

    """Traincrest Assist, milestone 1: a question goes in, an answer comes out.

Run from the project folder:  python cli.py
"""
import time

from app.config import MODEL, PROVIDER
from app.llm import get_client

SYSTEM_PROMPT = (
    "You are Traincrest Assist, the learner-support assistant of TrainCrest, a global technical "
    "training company. Be friendly, concise and practical. If you don't know something about "
    "TrainCrest's policies or a learner's enrolment, say so honestly."
)


def main():
    client = get_client()
    print(f"Traincrest Assist v0.1 [{PROVIDER} · {MODEL}]. Ask a question, or type 'exit'.\n")
    while True:
        question = input("You: ").strip()
        if question.lower() in {"exit", "quit"}:
            break
        if not question:
            continue

        start = time.perf_counter()
        response = client.chat.completions.create(
            model=MODEL,
            messages=[
                {"role": "system", "content": SYSTEM_PROMPT},
                {"role": "user", "content": question},
            ],
        )
        seconds = time.perf_counter() - start

        print(f"\nAssist: {response.choices[0].message.content.strip()}")
        u = response.usage
        print(f"  ({seconds:.1f}s · {u.prompt_tokens} in / {u.completion_tokens} out)\n")


if __name__ == "__main__":
    main()
    $ python cli.py
