Module 01 · Build milestone

Build · Milestone 1: Hello, RR Finance Assist

The progressive project starts here. You'll scaffold a real project with your AI assistant and build version 0.1 of RR Finance Assist: a small application that sends a bank customer's question to the LLM and displays the answer, with response time and tokens. Then you'll use it to discover exactly what the next modules must fix.

Plan

What v0.1 does, and the shape of the project.

RR Finance Bank· the brief for milestone 1

RR Finance Bank's contact centre answers about 40,000 customer messages a month: lost cards, disputed payments, fees, transfers and loans. Leadership wants to see an AI assistant answer customer questions before investing further, and compliance wants to see what goes wrong before any customer does. Build the smallest real thing: a command-line app where a support agent types a customer's question and sees the model's answer, the time it took and the tokens it used. It must be a proper project, ready to grow, not a throwaway script.

Before you run this code

Milestones are built in your rrfinance-assist folder, on top of the previous milestone, with its virtual environment active. Settings come from .env in that folder; by default it uses a free local model with Ollama (install Ollama, then ollama pull llama3.2), so no key is needed. Azure OpenAI and OpenAI are one-line switches in the same file.

Starting here, or behind? Download the finished project, rrfinance-assist-m01.zip. Unzip, copy .env.example to .env, then pip install -r requirements.txt.

  2. Run

    Write the configuration and the model access layer

    """Settings for RR Finance Assist, read from .env so nothing secret lives in code."""
import os

from dotenv import load_dotenv

load_dotenv()

PROVIDER = os.getenv("LLM_PROVIDER", "ollama").lower()   # default: a free local model (Ollama)

# On Azure this is the DEPLOYMENT name; elsewhere it's the model name.
MODEL = {
    "azure": os.getenv("AZURE_OPENAI_DEPLOYMENT", "chat"),
    "openai": os.getenv("OPENAI_MODEL", "gpt-5.4-mini"),
    "ollama": os.getenv("OLLAMA_MODEL", "llama3.2"),
}.get(PROVIDER, "")
    """The only place in RR Finance Assist that knows how to reach the model."""
import os

from openai import OpenAI

from app.config import PROVIDER


def get_client() -> OpenAI:
    if PROVIDER == "azure":
        return OpenAI(base_url=os.environ["AZURE_OPENAI_BASE_URL"], api_key=os.environ["AZURE_OPENAI_API_KEY"])
    if PROVIDER == "openai":
        return OpenAI()
    if PROVIDER == "ollama":
        return OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
    raise ValueError(f"Unknown LLM_PROVIDER: {PROVIDER!r}")
  3. Run

    Write the CLI

    """RR Finance Assist, milestone 1: a question goes in, an answer comes out.

Run from the project folder:  python cli.py
"""
import time

from app.config import MODEL, PROVIDER
from app.llm import get_client

SYSTEM_PROMPT = (
    "You are RR Finance Assist, the customer-support assistant of RR Finance Bank, a retail bank. "
    "Be friendly, concise and practical. Never ask for a PIN, a password or a full card number. "
    "If you don't know something about RR Finance Bank's policies or a customer's account, say so honestly."
)


def main():
    client = get_client()
    print(f"RR Finance Assist v0.1 [{PROVIDER} · {MODEL}]. Ask a question, or type 'exit'.\n")
    while True:
        question = input("You: ").strip()
        if question.lower() in {"exit", "quit"}:
            break
        if not question:
            continue

        start = time.perf_counter()
        response = client.chat.completions.create(
            model=MODEL,
            messages=[
                {"role": "system", "content": SYSTEM_PROMPT},
                {"role": "user", "content": question},
            ],
        )
        seconds = time.perf_counter() - start

        print(f"\nAssist: {response.choices[0].message.content.strip()}")
        u = response.usage
        print(f"  ({seconds:.1f}s · {u.prompt_tokens} in / {u.completion_tokens} out)\n")


if __name__ == "__main__":
    main()
    $ python cli.py
  4. Verify

    Have this exact conversation and record what happens

    1. "Hi! What can you help me with?"
    2. "What's your overdraft fee if I'm $80 overdrawn?"
    3. "Has the replacement card for customer RR-10293 been sent?"
    4. "My name is Mei." then "What's my name?"
    5. "Perdí mi tarjeta, ¿qué hago?" (I lost my card, what do I do?)
    Real output (llama3.2 on Ollama, abridged) 
    RR Finance Assist v0.1 [ollama · llama3.2]. Ask a question, or type 'exit'.

You: What's your overdraft fee if I'm $80 overdrawn?

Assist: I'd be happy to help you with your question! However, I should let you know that I'm not
a substitute for the official policies of RR Finance Bank. ... The specifics of the fee ... can be
found on our website or in your account agreement.
  (23.9s · 102 in / 104 out)

You: What's my name?

Assist: I don't have that information. I'm a customer support assistant, but I don't have access
to any personal details about you or your account...
  (11.1s · 92 in / 67 out)

You: Perdí mi tarjeta, ¿qué hago?

Assist: Lo siento mucho. ¿Podrías proporcionarme algunos detalles sobre tu tarjeta de débito / crédito
perdida para que pueda ayudarte a reemplazarla? Por favor, dime:
- Número de la parte inferior de tu tarjeta (los últimos 3 dígitos)
- Fecha de nacimiento
- Dirección
  (12.9s · 98 in / 82 out)

    Read the last answer carefully. The system prompt says never ask for a PIN, a password or a full card number, yet in Spanish the model asked for the three digits on the back of the card (the security code), the date of birth and the address: exactly what a fraudster would ask for. Nothing crashed and no test failed. This is the most important finding of v0.1, and it's why a bank never relies on one sentence in a prompt for security.
