Build · Milestone 11: Cost Estimates and Optimization Checks

M11 adds a Decimal-based estimate that accepts current rates from configuration instead of embedding vendor prices. Optimization options are evaluated against the quality and latency budgets from Modules 09 and 11.

RR Finance Bank· the brief for milestone 11

The bank needs a monthly forecast for about 40,000 incoming messages, with several turns per conversation. M11 provides a small cost helper for token volume and separately identifies costs it does not calculate.

Before you run this code

Milestones are built in your rrfinance-assist folder, on top of the previous milestone, with its virtual environment active. Settings come from .env in that folder; by default it uses a free local model with Ollama (install Ollama, then ollama pull llama3.2), so no key is needed. Azure OpenAI and OpenAI are one-line switches in the same file.

Starting here, or behind? Download the complete project as it should be at the start of this milestone, rrfinance-assist-m10.zip, or the finished one, rrfinance-assist-m11.zip. Unzip, copy .env.example to .env, then pip install -r requirements.txt.

"""Cost estimates from an explicitly supplied, current rate card."""

from dataclasses import dataclass
from decimal import Decimal


@dataclass(frozen=True)
class RateCard:
    input_usd_per_million: Decimal
    output_usd_per_million: Decimal

    def __post_init__(self) -> None:
        rates = (self.input_usd_per_million, self.output_usd_per_million)
        if any(not isinstance(rate, Decimal) for rate in rates):
            raise TypeError("Token rates must use Decimal values")
        if any(not rate.is_finite() or rate < 0 for rate in rates):
            raise ValueError("Token rates cannot be negative")


def estimate_monthly_cost(
    input_tokens_per_request: int,
    output_tokens_per_request: int,
    requests_per_month: int,
    rate_card: RateCard,
) -> Decimal:
    values = (
        input_tokens_per_request,
        output_tokens_per_request,
        requests_per_month,
    )
    if any(value < 0 for value in values):
        raise ValueError("Token counts and request volume cannot be negative")

    input_cost = (
        Decimal(input_tokens_per_request * requests_per_month)
        * rate_card.input_usd_per_million
        / Decimal(1_000_000)
    )
    output_cost = (
        Decimal(output_tokens_per_request * requests_per_month)
        * rate_card.output_usd_per_million
        / Decimal(1_000_000)
    )
    return input_cost + output_cost
Scope

The helper estimates input and output token charges only. It does not fetch current Azure or other provider prices, model retries, cache discounts, embedding calls, search, storage, network or staff review. Supply a dated rate card from the deployed service and add the other cost centers.
