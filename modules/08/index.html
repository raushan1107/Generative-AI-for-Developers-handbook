Module 08 · Overview

AI Application Architecture

A model call is one component, not an architecture. In this module, we add explicit routing and expiring session persistence to RR Finance Assist, then map where gateways, queues and traces belong—and what this local demo does not provide.

GatewayPersistent sessionsQueuesTracing
Learn 25 min · Build 45 min
1

Learn

Separate the product workflow from the infrastructure around it.

In the real world

Production AI systems combine application services with managed identity, storage, network controls and observability. A gateway helps apply shared model-access policies, while application code remains responsible for product-specific decisions.

In finance

RR Finance Assist keeps the signed-in customer context and pending approvals in the application tier. A model gateway may centralize endpoint access and quotas, but it cannot decide whether a transaction belongs to that customer or whether a dispute is eligible.

Traditional developer view

"Put each feature in a service and connect the APIs."

GenAI developer view

"Keep nondeterministic model work behind explicit application controls, and design state, cost and telemetry around every call."
