Document Ingestion

Real knowledge doesn't arrive as tidy markdown. It's wiki pages wrapped in navigation menus, text exports from old systems, spreadsheets of FAQs and three copies of the same playbook called FINAL. Ingestion turns that mess into clean text with the metadata RAG needs later. Whatever you skip here shows up as wrong answers later.

1

Learn

Garbage in, confident garbage out.

Definition

Document ingestion is the first stage of a RAG index: discovering source documents, extracting their text with a loader per format, cleaning and normalising it, attaching metadata (source, title, audience, date), and detecting duplicates and changes so the rest of the pipeline only processes what's new.

In plain words

Read every file, keep the words that matter, throw away the menus and footers, remember where each document came from and who may see it, and don't index the same thing twice.

Imagine this

A library receiving donations. Someone unpacks each box, throws away the packaging, notices that three boxes contain the same book, writes a catalogue card with the title and shelf, and marks reference-only books "not for loan". Skip that desk and the library fills with packaging and duplicates.

What good ingestion takes care of

ConcernWhy it matters for answersTypical fix
Page chrome (menus, footers, cookie banners)"Home · Sign out · 1,204 page views" ends up in chunks, wastes tokens and pollutes vectorsKeep <main>/<article>; drop nav, header, footer, aside, scripts
StructureHeadings become section titles, which chunking and citations rely onConvert headings to #/##, list items to -
Odd charactersNon-breaking spaces and Windows line endings make "identical" text differNormalise before hashing
DuplicatesThe same passage retrieved three times crowds out other sourcesContent hash; keep the first, report the rest
MetadataCitations need a source; access control needs an audience; freshness needs a dateAttach it now; it can't be guessed later
Change detectionRe-embedding everything nightly is slow and costlyStore the hash; reprocess only documents whose hash changed
Hard formatsScanned PDFs, tables, slides lose meaning as plain textOCR and layout-aware extraction (for example Azure AI Document Intelligence), tables kept as markdown
In the real world

Enterprise RAG projects spend a surprising share of their time here: connectors to SharePoint, Confluence or Google Drive; PDF extraction that keeps tables; stripping templates that appear on every page; and syncing permissions from the source system so the index knows who may read each document. On Azure, Azure AI Search indexers pull from Blob Storage, SharePoint and databases on a schedule, and its skills can crack documents, run OCR and split text, so the pipeline you write here maps onto configuration there.

Traditional developer view

"Read the files and dump the text into the index."

GenAI developer view

"Ingestion is data engineering. Every document gets a loader, cleaning, a stable id, a source, an audience and a hash, and I can print a report of what was loaded and what was skipped and why."

Common trap

Ingesting internal and public documents into one index with no audience metadata. The first time a learner's question matches the internal approvals page, the model happily quotes "exceptions up to $100: any support agent". Decide who may see each document at ingestion, while you still know where it came from.

Interview cue

"Ingestion extracts text per format, strips boilerplate, preserves structure, attaches metadata such as source, audience and date, and uses content hashes for de-duplication and incremental updates. Bad ingestion can't be fixed downstream."

    """Module 06 helper: document ingestion.
Load a folder of mixed documents (markdown, HTML, plain text, CSV FAQ) into one clean shape:
a title, markdown-style text with '## ' sections, the source file, who may see it, and a content
hash so a re-run can tell new, changed and unchanged documents apart."""
import csv
import hashlib
import re
from dataclasses import dataclass
from html.parser import HTMLParser
from pathlib import Path

DATA = Path(__file__).parent / "data"


@dataclass
class Doc:
    id: str          # stable: the file name without extension
    title: str
    text: str        # clean text; sections start with "## "
    source: str      # file name, shown in citations
    audience: str    # "public" or "staff": who may see it (a retrieval filter later)
    hash: str = ""


def clean(text: str) -> str:
    """Normalise what copy-paste and exports leave behind: odd spaces, line endings, blank-line runs."""
    text = text.replace("\r\n", "\n").replace("\r", "\n").replace(" ", " ").replace("​", "")
    text = "\n".join(line.rstrip() for line in text.split("\n"))
    return re.sub(r"\n{3,}", "\n\n", text).strip()


def content_hash(text: str) -> str:
    return hashlib.sha1(text.encode("utf-8")).hexdigest()[:12]


def load_markdown(path: Path) -> tuple[str, str]:
    text = clean(path.read_text(encoding="utf-8"))
    title = re.search(r"^# (.+)$", text, re.M)
    return (title.group(1).strip() if title else path.stem), text


def sentence_case(text: str) -> str:
    """'RULE FR-12 ALERTS' -> 'Rule FR-12 alerts': lower-case words, but keep codes with digits."""
    words = [w if any(ch.isdigit() for ch in w) else w.lower() for w in text.split()]
    out = " ".join(words)
    return out[:1].upper() + out[1:]


def load_text(path: Path) -> tuple[str, str]:
    """Plain text from an old system: first line is the title, UPPER-CASE lines are headings."""
    lines = clean(path.read_text(encoding="utf-8")).split("\n")
    title = sentence_case(lines[0])
    body = [f"## {sentence_case(line)}" if line.isupper() and len(line.split()) <= 8 else line
            for line in lines[1:]]
    return title, f"# {title}\n" + "\n".join(body)


class _MainText(HTMLParser):
    """Keep the page's content, drop the chrome: navigation, header, footer, sidebars, scripts, styles."""
    SKIP = {"nav", "header", "footer", "aside", "script", "style", "head"}
    PREFIX = {"h1": "# ", "h2": "## ", "h3": "### ", "li": "- "}

    def __init__(self):
        super().__init__()
        self.out, self.skipping = [], 0

    def handle_starttag(self, tag, attrs):
        if tag in self.SKIP:
            self.skipping += 1
        elif not self.skipping and tag in self.PREFIX | {"p": ""}:
            self.out.append("\n\n" if tag != "li" else "\n")
            self.out.append(self.PREFIX.get(tag, ""))

    def handle_endtag(self, tag):
        if tag in self.SKIP and self.skipping:
            self.skipping -= 1

    def handle_data(self, data):
        if not self.skipping:
            self.out.append(re.sub(r"\s+", " ", data))


def load_html(path: Path) -> tuple[str, str]:
    parser = _MainText()
    parser.feed(path.read_text(encoding="utf-8"))          # entities like &rsaquo; are decoded for us
    text = clean("".join(parser.out))
    text = "\n".join(line.strip() for line in text.split("\n"))
    title = re.search(r"^# (.+)$", text, re.M)
    return (title.group(1).strip() if title else path.stem), clean(text)


def load_csv_faq(path: Path) -> tuple[str, str]:
    """A question,answer spreadsheet: each row becomes one '## question' section."""
    title = re.sub(r"\bfaq\b", "FAQ", sentence_case(path.stem.replace("-", " ")))
    with path.open(encoding="utf-8", newline="") as f:
        rows = list(csv.DictReader(f))
    sections = [f"## {r['question'].strip()}\n{r['answer'].strip()}" for r in rows if r.get("answer")]
    return title, f"# {title}\n\n" + "\n\n".join(sections)


LOADERS = {".md": load_markdown, ".html": load_html, ".htm": load_html, ".txt": load_text, ".csv": load_csv_faq}


def load_folder(folder, audience: str):
    """Return (docs, report). The report has one line per file: loaded, or why it was skipped."""
    docs, report, seen = [], [], {}
    for path in sorted(Path(folder).iterdir()):
        loader = LOADERS.get(path.suffix.lower())
        if loader is None:
            report.append((path.name, "skipped: unsupported format"))
            continue
        title, text = loader(path)
        digest = content_hash(text)
        if len(text) < 40:
            report.append((path.name, "skipped: empty"))
        elif digest in seen:
            report.append((path.name, f"skipped: duplicate of {seen[digest]}"))
        else:
            seen[digest] = path.name
            docs.append(Doc(path.stem, title, text, path.name, audience, digest))
            report.append((path.name, f"loaded: {text.count(chr(10) + '## ')} sections, {len(text)} chars"))
    return docs, report


def load_knowledge_base():
    """RR Finance Bank's knowledge base: public help-centre articles plus internal staff documents."""
    public, _ = load_folder(DATA / "help", "public")
    staff, _ = load_folder(DATA / "internal", "staff")
    return public + staff

3

Check

Ingestion.

1. Why hash the text after cleaning rather than the raw file?

Two copies of the same document can differ in bytes only (Windows line endings, trailing spaces, non-breaking spaces). Hashing the cleaned text catches them as duplicates, and a re-saved but unchanged file isn't re-embedded.

2. Which metadata would you refuse to ship without, and why?

Source (needed for citations and debugging) and audience or permissions (needed so retrieval never shows a user something they may not see). Both are known at ingestion and can't be reconstructed later.

3. A wiki page's navigation menu is indexed with every page. What goes wrong?

Every chunk contains the same menu words, so vectors drift toward each other, searches for "support" match every page, and the model gets wasted tokens of "Home · Teams · Sign out" in its context.

Takeaway

Ingestion produces clean text, real structure, a source, an audience and a hash for every document, and a report of what it skipped. Every later stage relies on it.
