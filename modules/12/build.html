Build · Milestone 12: Release and Operational Checks

M12 adds local preflight helpers for release artifacts and operational thresholds. It does not deploy containers, provision Azure resources, configure real alerts or certify the service for production.

Release manifestHealth thresholdsRollback80 tests
Plan 10 min · Build 30 min · Verify 20 min
1

Plan

Make release provenance and health signals reviewable.

RR Finance Bank· the brief for milestone 12

The service must record which versioned artifacts were approved, require a rollback target, and expose explicit health thresholds. The production team must connect these checks to its CI/CD platform, monitoring system, runbook, model-risk review and approved deployment environment.

2

Build

Review the preflight checks and their limits.

HelperChecksDoes not check
validate_release_manifest()Required release fields and digest shapeRegistry existence, signatures, approval or deployment
health_failures()Missing or over-limit operational/quality metricsMetric collection, alert routing, SLO selection or incident response
Scope

Passing these local checks is not production certification. The repository milestone does not create Azure resources, container images, CI/CD workflows or live monitoring. The production owner must implement and exercise those controls in the target environment.

3

Verify

Run the full M12 test suite.

Get the runnable project

The code panels in this handbook are examples; their Copy buttons do not create local files. Download the complete Module 12 project and extract it. Open the top-level rrfinance-assist folder, which contains the application, tests, pytest.ini and requirements.txt. Run the test command below from that folder; the test files are already included.

If needed, install dependencies there with python -m pip install -r requirements.txt. The suite runs offline and does not deploy cloud resources.

Build check 12

Verify milestone 12

Python · pytestoffline

Goal: run inherited tests and the release/health preflight tests without external services.

  1. Run

    Suite

    $ python -m pytest -q
    Expected result
    80 passed
  2. Verify
    • A manifest without rollback information fails.
    • Missing health metrics fail closed.
    • No deployment or cloud resource is created by this command.
Milestone complete

M12 provides testable preflight checks and an operations checklist. Live cloud deployment, monitoring configuration and formal model-risk approval remain environment-specific responsibilities.
