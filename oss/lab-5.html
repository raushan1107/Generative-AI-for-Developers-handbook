Lab 5 · Performance, Cost and Release

Prepare a small release preflight without deploying anything. Compare simple route rules, estimate cost from clearly labeled fictional rates, see how model and prompt versions affect a cache key, and validate a release manifest and health limits. Every check is local and deliberately narrower than a production deployment or monitoring system.

Modules 11–12Routing and cache keysCost estimateRelease preflight≈ 3 hours
Estimated time: 3 hours

Lab overview

ObjectivesApply explicit demo routing rules · estimate monthly token cost using supplied rates · build a versioned cache key · validate required release-manifest fields and digest syntax · compare observed health metrics with limits · separate preflight checks from deployment and monitoring
PrerequisitesLab 0 Python environment · Lab 4 completed · Modules 11–12 demonstrated · no Ollama model, cloud account or network access required
ScenarioRR Finance Assist is preparing a fictional release. The rate card, routes, manifest and health observations are illustrative inputs, not vendor prices or an approved bank policy.

Exercise 1 · Compare routes and estimate token cost

Module 11 introduces routing and budgets. This example uses a small, transparent decision table and a supplied token rate card; neither is an automatically safe production policy.

Task 1: Run the estimate and inspect its assumptions

  1. Open l5_release.py and read choose_demo_route() and estimate_monthly_cost(): 
    """Lab 5: illustrative routing, token-cost estimates and release preflight checks."""

import math
import hashlib
import json
import re
from collections.abc import Mapping
from dataclasses import dataclass
from decimal import Decimal


@dataclass(frozen=True)
class RateCard:
    input_usd_per_million: Decimal
    output_usd_per_million: Decimal


def estimate_monthly_cost(
    input_tokens_per_request: int,
    output_tokens_per_request: int,
    requests_per_month: int,
    rate_card: RateCard,
) -> Decimal:
    counts = (
        input_tokens_per_request,
        output_tokens_per_request,
        requests_per_month,
    )
    if any(not isinstance(value, int) for value in counts):
        raise TypeError("Token counts and request volume must be integers")
    if any(value < 0 for value in counts):
        raise ValueError("Token counts and request volume must be non-negative")
    if any(isinstance(value, bool) for value in counts):
        raise TypeError("Token counts and request volume must be integers")
    rates = (rate_card.input_usd_per_million, rate_card.output_usd_per_million)
    if any(not isinstance(rate, Decimal) for rate in rates):
        raise TypeError("Rates must be Decimal values")
    if any(not rate.is_finite() or rate < 0 for rate in rates):
        raise ValueError("Rates must be finite and non-negative")

    input_cost = (
        Decimal(input_tokens_per_request * requests_per_month)
        * rate_card.input_usd_per_million
        / Decimal(1_000_000)
    )
    output_cost = (
        Decimal(output_tokens_per_request * requests_per_month)
        * rate_card.output_usd_per_million
        / Decimal(1_000_000)
    )
    return input_cost + output_cost


def cache_key(model: str, prompt_version: str, messages: list[dict[str, str]]) -> str:
    if not model or not prompt_version:
        raise ValueError("Model and prompt version are required")
    canonical = json.dumps(
        {"model": model, "prompt_version": prompt_version, "messages": messages},
        sort_keys=True,
        separators=(",", ":"),
    ).encode("utf-8")
    return hashlib.sha256(canonical).hexdigest()


def choose_demo_route(task: str, data_classification: str) -> str:
    if task not in {"simple", "complex"}:
        raise ValueError("Task must be 'simple' or 'complex'")
    if data_classification not in {"public", "customer"}:
        raise ValueError("Data classification must be 'public' or 'customer'")
    if data_classification == "customer":
        return "approved-private-route"
    return "small-model" if task == "simple" else "large-model"


REQUIRED_FIELDS = (
    "release_id",
    "model_deployment",
    "prompt_version",
    "evaluation_dataset",
    "image_digest",
    "rollback_image_digest",
)
IMAGE_DIGEST = re.compile(r"^sha256:[0-9a-f]{64}$")
HEALTH_LIMITS = {
    "p95_latency_ms": 1500.0,
    "error_rate": 0.02,
    "citation_id_failure_rate": 0.05,
}


def validate_manifest(manifest: Mapping[str, str]) -> list[str]:
    failures = [
        field for field in REQUIRED_FIELDS
        if not isinstance(manifest.get(field), str) or not manifest[field].strip()
    ]
    for field in ("image_digest", "rollback_image_digest"):
        value = manifest.get(field, "")
        if isinstance(value, str) and value and not IMAGE_DIGEST.fullmatch(value):
            failures.append(field)
    return failures


def health_failures(
    observed: Mapping[str, float], limits: Mapping[str, float]
) -> list[str]:
    failures: list[str] = []
    for name in HEALTH_LIMITS:
        value = observed.get(name)
        limit = limits.get(name)
        if (
            not isinstance(value, (int, float))
            or isinstance(value, bool)
            or not math.isfinite(value)
            or not isinstance(limit, (int, float))
            or isinstance(limit, bool)
            or not math.isfinite(limit)
            or value < 0
            or limit < 0
            or value > limit
        ):
            failures.append(name)
    return failures


def main() -> None:
    illustrative_rates = RateCard(Decimal("0.50"), Decimal("2.00"))
    monthly_cost = estimate_monthly_cost(1000, 200, 10_000, illustrative_rates)
    print(f"Illustrative monthly token estimate: ${monthly_cost:.2f}")
    key = cache_key(
        "example-model",
        "assist-v1",
        [{"role": "user", "content": "What are the bank's opening hours?"}],
    )
    print(f"Example cache key: {key[:12]}... (key only; no response cache is implemented)")

    for task, data_classification in (
        ("simple", "public"),
        ("complex", "public"),
        ("simple", "customer"),
    ):
        route = choose_demo_route(task, data_classification)
        print(f"Route {task}/{data_classification}: {route}")

    manifest = {
        "release_id": "demo-2026-01",
        "model_deployment": "example-model",
        "prompt_version": "assist-v1",
        "evaluation_dataset": "synthetic-eval-v1",
        "image_digest": "sha256:" + "a" * 64,
        "rollback_image_digest": "sha256:" + "b" * 64,
    }
    manifest_failures = validate_manifest(manifest)
    health = {
        "p95_latency_ms": 1200.0,
        "error_rate": 0.01,
        "citation_id_failure_rate": 0.02,
    }
    health_failures_found = health_failures(health, HEALTH_LIMITS)
    passed = not manifest_failures and not health_failures_found
    print(f"Local preflight: {'PASS' if passed else 'BLOCK'}")
    print("Placeholder digests prove only string shape, not artifact provenance.")
    print("Nothing was deployed or sent to a model provider.")


if __name__ == "__main__":
    main()

  3. Check the estimate: 10 million input tokens at $0.50 per million is $5; 2 million output tokens at $2.00 per million is $4. The total is $9. Both rates are fictional teaching values. A real estimate must use current provider pricing and account for other charges and discounts.
  4. Change request volume or the supplied rates and recalculate. Then inspect the route outcomes. The route names are labels only: they do not call a model, establish data residency, or authorize handling of customer information.
Checkpoint

Exercise 2 · Create a versioned cache key

The hash includes the model, prompt version and messages, so changing the prompt version changes the key even when the user message stays the same.

Task 1: Verify key stability and limits

  1. Read cache_key() and the corresponding test in test_l5_release.py.
  2. Run the tests: 
    $ python -m unittest test_l5_release
  3. Change the prompt version from assist-v1 to assist-v2 and compare the key. Restore the original value after the experiment.
  4. Notice what is deliberately absent: this script does not store or return cached responses, set a TTL, isolate users, or check whether a result is still authorized. Do not build a shared cache for private banking responses from this hash alone.
Checkpoint

You can explain why a cache key needs relevant model and prompt versions, and why a deterministic hash is not a complete cache design.

Exercise 3 · Run a release and health preflight

Module 12 covers release controls and operations. This script checks required fields, digest-string shape and three supplied health thresholds; it does not verify artifacts or observe a running service.

Task 1: Exercise the preflight

  1. Inspect validate_manifest(), health_failures() and HEALTH_LIMITS. The digest examples use repeated letters to demonstrate syntax only.
  2. Run the tests. Then change p95_latency_ms in the script to 1600 and rerun it; the local preflight should block on that metric. Restore the sample value afterward.
  3. Remove the rollback digest from manifest or replace it with an invalid string, then rerun the program. Check that the manifest validation reports a failure. Restore the original sample.
  4. Discuss what a real release needs in addition: verified artifact provenance, deployment permissions, secrets management, live health telemetry, rollback execution, incident ownership and tested recovery procedures.
Checkpoint

You can trigger a failed health check and explain why a passing local preflight does not certify or deploy a production release.

Troubleshooting

SymptomFix
The displayed cost is not $9.00Check the token counts and the illustrative input/output rates in main(); the calculation uses Decimal arithmetic.
The cache key changed unexpectedlyCompare the model, prompt version and message data. Any of them changes the canonical JSON and therefore the hash.
The health check blocksCompare each observed value to its matching limit. Restore the original sample only after you have recorded which check failed.
The manifest passes with a fake digestExpected: the check validates only the string's format. It does not retrieve the image or prove its integrity or origin.

Review and cleanup

  • Cost projections depend on token usage and the current, applicable rate card; the sample prices are fictional.
  • Routing decisions need explicit quality, privacy, latency and availability requirements, not only a task label.
  • Cache isolation, retention, invalidation and authorization are part of the design, not properties supplied by a hash.
  • A release preflight is one check in a delivery process; it does not deploy, monitor or certify the service.

Cleanup: these programs create no persistent cache or release files. Keep the scripts and tests so you can rerun the checks.
