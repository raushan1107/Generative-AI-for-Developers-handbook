Lab 2 · Tools and Semantic Search with Open Models

In this lab your open model starts working with your code. First it returns data in a shape you define; then it calls your functions to search a catalogue, look up a learner and open a ticket; then you turn text into vectors and build a search engine that finds help articles by meaning. These are the hands-on exercises of Modules 04 and 05.

Exercise 1 · Structured output from a schema

Task 1: Extract a course request as validated data

  1. Create l2_structured.py: 
    """Lab 2, Exercise 1: schema-based output. Pydantic defines the shape; the model must return JSON that
matches it (Ollama supports JSON-schema structured outputs); code validates the result.
Run:  python l2_structured.py"""
from typing import Literal, Optional

from pydantic import BaseModel, Field

from client import CHAT_MODEL, get_client


class CourseRequest(BaseModel):
    topic: str = Field(description="What the learner wants to learn, in a few words")
    level: Optional[Literal["beginner", "intermediate", "advanced"]]
    max_price_usd: Optional[int] = Field(description="Budget in US dollars, or null")
    format: Optional[Literal["live-online", "classroom", "self-paced"]]


REQUESTS = [
    "I'm new to the cloud and want something on Azure basics, under 400 dollars please.",
    "Looking for an advanced course on building RAG apps, online with a trainer.",
    "Any self-paced Python course? Budget is about $300.",
]
client = get_client()
for text in REQUESTS:
    completion = client.chat.completions.parse(
        model=CHAT_MODEL, temperature=0, response_format=CourseRequest,
        messages=[{"role": "system", "content": "Extract the learner's course request. Use null for anything not stated."},
                  {"role": "user", "content": text}])
    print(f"{text}\n  -> {completion.choices[0].message.parsed}\n")
  2. Note client.chat.completions.parse(... response_format=CourseRequest): the OpenAI library turns the Pydantic class into a JSON Schema, Ollama constrains the model's output to it, and the library returns a CourseRequest object. If it says parse doesn't exist, run pip install -U openai.
  3. Run it: 
    $ python l2_structured.py
    Real output with llama3.2 (yours will differ) 
    I'm new to the cloud and want something on Azure basics, under 400 dollars please.
  -> topic='Azure Basics' level='beginner' max_price_usd=400 format=None

Looking for an advanced course on building RAG apps, online with a trainer.
  -> topic='RAG app development' level='advanced' max_price_usd=None format='live-online'

Any self-paced Python course? Budget is about $300.
  -> topic='Python' level='beginner' max_price_usd=300 format='self-paced'
  4. Check each result against the request. A schema guarantees the shape (only allowed values for level and format, an integer price) but not that every value is right. Where did the model fill a value the learner didn't state?
Checkpoint

You get CourseRequest objects, not text, and can say what a schema does and doesn't guarantee.

Exercise 2 · An assistant that calls your functions

Module 04's hands-on exercise: an AI assistant that calls application functions: search products (here, courses), retrieve customer information, create a support ticket and check order (enrolment) status.

Task 1: Build the assistant

  1. Create l2_tools.py: 
    """Lab 2, Exercise 2: an AI assistant that calls application functions: search the catalogue,
retrieve the learner's information, check an enrolment's status and create a support ticket.
The model asks for a function; this code decides whether and how it runs.
Run:  python l2_tools.py "Which beginner courses cost less than $300?" """
import json
import sys
import uuid
from pathlib import Path

from client import AGENT_MODEL, get_client

COURSES = json.loads((Path(__file__).parent / "data" / "courses.json").read_text(encoding="utf-8"))
LEARNERS = {"L-MEI": {"name": "Mei Chen", "country": "Singapore", "enrolments": ["TC-10293", "TC-10477"]}}
ENROLMENTS = {"TC-10293": {"course": "AI-102: Azure AI Engineer", "status": "completed", "certificate": "issued"},
              "TC-10477": {"course": "Building RAG Applications", "status": "confirmed", "starts_in_days": 10}}
SIGNED_IN = "L-MEI"            # the app knows who is signed in; the model never chooses this


# ---------------- the application functions (plain Python)
def search_courses(text: str = "", level: str | None = None, max_price_usd: int | None = None):
    # Models sometimes send numbers as text ("300"): accept them, like any API that faces untrusted input.
    max_price_usd = int(float(max_price_usd)) if max_price_usd not in (None, "") else None
    hits = [c for c in COURSES if (not level or c["level"] == level)
            and (max_price_usd is None or c["price_usd"] <= max_price_usd)
            and (not text or text.lower() in (c["title"] + " " + c["description"]).lower())]
    return [{k: c[k] for k in ("id", "title", "level", "price_usd")} for c in hits[:5]]


def get_my_profile():
    me = LEARNERS[SIGNED_IN]
    return {**me, "enrolments": [{"enrolment_id": e, "course": ENROLMENTS[e]["course"]} for e in me["enrolments"]]}


def check_enrolment_status(enrolment_id: str):
    if enrolment_id not in LEARNERS[SIGNED_IN]["enrolments"]:
        return {"error": "not one of the signed-in learner's enrolments; call get_my_profile to see them"}
    return ENROLMENTS[enrolment_id]


def create_support_ticket(summary: str, category: str):
    return {"ticket_id": "T-" + uuid.uuid4().hex[:6].upper(), "status": "created", "category": category}


FUNCTIONS = {f.__name__: f for f in (search_courses, get_my_profile, check_enrolment_status, create_support_ticket)}

# ---------------- how the model sees them (JSON Schema)
TOOLS = [
    {"type": "function", "function": {
        "name": "search_courses", "description": "Search the TrainCrest course catalogue by keyword, level and maximum price.",
        "parameters": {"type": "object", "properties": {
            "text": {"type": "string", "description": "One keyword, e.g. 'azure' or 'python'; empty for any"},
            "level": {"type": "string", "enum": ["beginner", "intermediate", "advanced"]},
            "max_price_usd": {"type": "integer", "description": "Highest price in US dollars"}}}}},
    {"type": "function", "function": {
        "name": "get_my_profile", "description": "The signed-in learner's name, country, and enrolments with course names.",
        "parameters": {"type": "object", "properties": {}}}},
    {"type": "function", "function": {
        "name": "check_enrolment_status", "description": "Status of one of the signed-in learner's enrolments.",
        "parameters": {"type": "object", "properties": {
            "enrolment_id": {"type": "string", "description": "Like TC-12345, from get_my_profile"}},
            "required": ["enrolment_id"]}}},
    {"type": "function", "function": {
        "name": "create_support_ticket", "description": "Create a ticket for the human support team.",
        "parameters": {"type": "object", "properties": {
            "summary": {"type": "string"},
            "category": {"type": "string", "enum": ["billing", "scheduling", "lab_access", "other"]}},
            "required": ["summary", "category"]}}},
]


def ask(question: str, max_rounds: int = 5) -> str:
    client = get_client()
    messages = [{"role": "system", "content": "You are Traincrest Assist. Use the tools for facts; never guess IDs. "
                                              "The learner can't call functions: call them yourself, starting with "
                                              "get_my_profile when you need an enrolment ID. Answer in at most 60 words."},
                {"role": "user", "content": question}]
    for _ in range(max_rounds):
        msg = client.chat.completions.create(model=AGENT_MODEL, messages=messages, tools=TOOLS).choices[0].message
        if not msg.tool_calls:
            return msg.content.strip()
        messages.append(msg)
        for call in msg.tool_calls:
            args = json.loads(call.function.arguments or "{}")
            func = FUNCTIONS.get(call.function.name)
            try:
                result = func(**args) if func else {"error": f"unknown function {call.function.name}"}
            except TypeError as e:                       # wrong or missing arguments
                result = {"error": f"bad arguments: {e}"}
            print(f"  -> {call.function.name}({args}) = {json.dumps(result)[:90]}")
            messages.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(result)})
    return "Sorry, that took too many steps."


if __name__ == "__main__":
    questions = sys.argv[1:] or ["Which beginner courses cost less than $300?",
                                 "What's the status of my RAG course?",
                                 "My invoice is wrong, please open a ticket for me."]
    for q in questions:
        print(f"Q: {q}")
        print(f"A: {ask(q)}\n")
  2. Read the three parts: the functions are ordinary Python; TOOLS describes them to the model as JSON Schema; ask() is the tool loop: call the model, run any function it asks for, send the result back, repeat until it answers (at most 5 rounds).
  3. This exercise uses AGENT_MODEL from .env, the model for tool calling. Set it to qwen2.5:7b if you pulled it: llama3.2 often writes a tool call as text, or tells you to call the functions yourself.
  4. Notice SIGNED_IN = "L-MEI": the app decides who the learner is. No tool takes a learner ID from the model, so a prompt can't make it read someone else's data.

Exercise 3 · Embeddings: meaning as numbers

  1. Create l2_embeddings.py: 
    """Lab 2, Exercise 3: embeddings turn text into vectors; similar meanings get similar vectors.
Run:  python l2_embeddings.py"""
import numpy as np

from client import EMBED_MODEL, get_embed_client

TEXTS = [
    "How do I get my money back?",
    "Can I have a refund for my course?",
    "¿Cómo pido un reembolso?",
    "My lab says quota exceeded",
    "The sandbox won't start",
    "What's the weather in Paris?",
]
response = get_embed_client().embeddings.create(model=EMBED_MODEL, input=TEXTS)
vectors = np.array([d.embedding for d in response.data])
vectors /= np.linalg.norm(vectors, axis=1, keepdims=True)          # length 1: dot product = cosine similarity
print(f"{len(TEXTS)} texts -> vectors of {vectors.shape[1]} numbers. First five of the first: "
      f"{np.round(vectors[0][:5], 3).tolist()}\n")

similarity = vectors @ vectors.T
for i, text in enumerate(TEXTS):
    j = max((k for k in range(len(TEXTS)) if k != i), key=lambda k: similarity[i, k])
    print(f"{text:38} closest: {TEXTS[j]:38} ({similarity[i, j]:.2f})")
  2. Run it: 
    $ python l2_embeddings.py
    Real output with nomic-embed-text 
    6 texts -> vectors of 768 numbers. First five of the first: [0.063, 0.024, -0.171, 0.017, 0.036]

How do I get my money back?            closest: Can I have a refund for my course?     (0.67)
Can I have a refund for my course?     closest: How do I get my money back?            (0.67)
¿Cómo pido un reembolso?               closest: How do I get my money back?            (0.44)
My lab says quota exceeded             closest: Can I have a refund for my course?     (0.40)
The sandbox won't start                closest: How do I get my money back?            (0.38)
What's the weather in Paris?           closest: Can I have a refund for my course?     (0.35)
  3. Each text became 768 numbers. Texts with similar meaning have a high cosine similarity even when they share no words. Look at the Spanish sentence: how close is it to its English equivalents with this mostly English model?

Exercise 4 · A semantic search app

Module 05's hands-on exercise: a semantic search application over a collection of documents.

Task 1: Build the index and the search

  1. Create l2_search.py: 
    """Lab 2, Exercise 4: a semantic search application over TrainCrest's help centre.
Index: split each article by heading (keeping its introduction), embed every section once and save it.
Search: embed the question, rank by meaning (cosine) and by keywords (BM25), merge the two rankings (RRF).
Run:  python l2_search.py "money back if the trainer is ill" """
import json
import re
import sys
from pathlib import Path

import numpy as np
from rank_bm25 import BM25Okapi

from client import EMBED_MODEL, get_embed_client

HELP = Path(__file__).parent / "data" / "help"
INDEX = Path(__file__).parent / "data" / "search_index.json"


def sections():
    for path in sorted(HELP.glob("*.md")):
        text = path.read_text(encoding="utf-8")
        title = re.search(r"^# (.+)$", text, re.M).group(1)
        intro, *parts = re.split(r"^## ", re.sub(r"^# .+\n", "", text, count=1), flags=re.M)
        pieces = ([("Overview", intro)] if intro.strip() else []) + [p.partition("\n")[::2] for p in parts]
        for heading, body in pieces:
            yield {"source": path.name, "title": f"{title} > {heading.strip()}",
                   "text": f"{title} > {heading.strip()}\n{body.strip()}"}


def embed(texts):
    data = get_embed_client().embeddings.create(model=EMBED_MODEL, input=texts).data
    v = np.array([d.embedding for d in data])
    return v / np.linalg.norm(v, axis=1, keepdims=True)


def load_index():
    """Build the index the first time (a few seconds), then reuse it."""
    if INDEX.exists():
        saved = json.loads(INDEX.read_text(encoding="utf-8"))
        if saved["model"] == EMBED_MODEL:                    # vectors from another model can't be compared
            return saved["docs"], np.array(saved["vectors"])
    docs = list(sections())
    vectors = embed([d["text"] for d in docs])
    INDEX.write_text(json.dumps({"model": EMBED_MODEL, "docs": docs, "vectors": vectors.tolist()}), encoding="utf-8")
    print(f"(indexed {len(docs)} help sections with {EMBED_MODEL})")
    return docs, vectors


def words(text):
    """A tiny analyzer: lower-case, keep codes like lab-503 whole, fold simple plurals (discounts -> discount)."""
    found = re.findall(r"[a-z0-9]+(?:-[a-z0-9]+)*", text.lower())
    return [w[:-1] if len(w) > 3 and w.endswith("s") and not w.endswith("ss") else w for w in found]


def search(query, docs, vectors, k=3):
    cosine = vectors @ embed([query])[0]
    by_meaning = list(np.argsort(-cosine))
    keyword_scores = BM25Okapi([words(d["text"]) for d in docs]).get_scores(words(query))
    by_keyword = [i for i in np.argsort(-keyword_scores) if keyword_scores[i] > 0]
    rrf = {}
    for ranking in (by_meaning, by_keyword):
        for rank, i in enumerate(ranking, start=1):
            rrf[i] = rrf.get(i, 0) + 1 / (60 + rank)
    best = sorted(rrf, key=lambda i: -rrf[i])[:k]
    return [(docs[i], float(cosine[i])) for i in best]


if __name__ == "__main__":
    docs, vectors = load_index()
    queries = sys.argv[1:] or ["money back if the trainer is ill", "LAB-503", "pay in parts", "discount for my team"]
    for q in queries:
        print(f"\n{q}")
        for doc, score in search(q, docs, vectors):
            print(f"  {score:.2f}  {doc['title']}")
  2. Follow the pipeline in the code: sections() splits each article at its headings (keeping the introduction), load_index() embeds every section once and saves the vectors to data/search_index.json, and search() ranks by meaning and by keywords and merges the two rankings with Reciprocal Rank Fusion.

Troubleshooting

SymptomFix

does not support toolsThe chosen model has no tool support in Ollama. Use llama3.2 or qwen2.5.

Review and cleanup

  • A schema makes output shape reliable; validation and common sense check the values.
  • Function calling is a loop you control: the model asks, your code decides and runs, the result goes back.
  • Identity comes from the app, never from the model's arguments.
  • Embeddings turn meaning into vectors; hybrid search combines meaning with exact keywords.

Cleanup: keep data/search_index.json; Lab 3 builds a similar index for its knowledge assistant.
