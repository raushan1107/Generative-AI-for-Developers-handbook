Lab 3 · RAG and Agents with Open Models

You'll build the two projects of Part III with open models. First a company knowledge assistant: it ingests TrainCrest's help articles and staff documents, retrieves the right sections for each question, answers only from them and cites them, and shows staff-only documents only to staff. Then an agent that works through a request step by step and stops for your approval before it changes a booking.

Exercise 1 · A company knowledge assistant (RAG)

Module 06's hands-on project: a company knowledge assistant that answers questions from internal documents.

Task 1: Look at the documents

  1. Open a few files in data/help/ (public help articles) and all three in data/internal/ (staff only): a markdown playbook, a plain-text runbook with upper-case headings, and a CSV FAQ. Real knowledge bases mix formats like this.
  2. Find one fact that appears only in an internal document, for example the maximum class size in staff-faq.csv. You'll ask about it later.

Task 2: Build the assistant

  1. Create l3_knowledge.py: 
    """Lab 3, Exercise 1: a Company Knowledge Assistant (RAG) that answers questions from TrainCrest's own
documents, public help articles and internal staff documents, and cites its sources.
Run:  python l3_knowledge.py            (learner view: help centre only)
      python l3_knowledge.py --staff    (staff view: help centre + internal documents)"""
import csv
import json
import re
import sys
from pathlib import Path

import numpy as np

from client import CHAT_MODEL, EMBED_MODEL, get_client, get_embed_client

DATA = Path(__file__).parent / "data"
INDEX = DATA / "kb_index.json"
MIN_SCORE = 0.55          # relevance floor for nomic-embed-text; other embedding models need their own value
NOT_FOUND = "NOT_FOUND"


# ---------------- 1. ingest: every format becomes "# Title" + "## Section" text
def read_document(path: Path) -> str:
    if path.suffix == ".csv":                                   # question,answer rows
        rows = list(csv.DictReader(path.open(encoding="utf-8")))
        return f"# {path.stem.replace('-', ' ').title()}\n" + "\n".join(f"## {r['question']}\n{r['answer']}" for r in rows)
    text = path.read_text(encoding="utf-8")
    if path.suffix == ".txt":                                   # UPPER-CASE lines are headings
        lines = text.splitlines()
        return f"# {lines[0].title()}\n" + "\n".join(f"## {l.capitalize()}" if l.isupper() else l for l in lines[1:])
    return text


# ---------------- 2. chunk: one chunk per section, intro included, title on every chunk
def chunks(path: Path, audience: str):
    text = read_document(path)
    title = re.search(r"^# (.+)$", text, re.M).group(1).strip()
    intro, *parts = re.split(r"^## ", re.sub(r"^# .+\n", "", text, count=1), flags=re.M)
    sections = ([("Overview", intro)] if intro.strip() else []) + [p.partition("\n")[::2] for p in parts]
    for heading, body in sections:
        yield {"title": f"{title} > {heading.strip()}", "source": path.name, "audience": audience,
               "text": f"{title} > {heading.strip()}\n{body.strip()}"}


def embed(texts):
    data = get_embed_client().embeddings.create(model=EMBED_MODEL, input=texts).data
    v = np.array([d.embedding for d in data])
    return v / np.linalg.norm(v, axis=1, keepdims=True)


# ---------------- 3. embed and store (once; rebuilt if the embedding model changes)
def load_index():
    if INDEX.exists():
        saved = json.loads(INDEX.read_text(encoding="utf-8"))
        if saved["model"] == EMBED_MODEL:
            return saved["chunks"], np.array(saved["vectors"])
    items = [c for folder, audience in (("help", "public"), ("internal", "staff"))
             for path in sorted((DATA / folder).iterdir()) for c in chunks(path, audience)]
    vectors = embed([c["text"] for c in items])
    INDEX.write_text(json.dumps({"model": EMBED_MODEL, "chunks": items, "vectors": vectors.tolist()}), encoding="utf-8")
    return items, vectors


# ---------------- 4. retrieve: only what this audience may see, only above the floor
def retrieve(question, items, vectors, audience, k=4):
    allowed = [i for i, c in enumerate(items) if c["audience"] in audience]
    scores = vectors[allowed] @ embed([question])[0]
    best = [allowed[j] for j in np.argsort(-scores)[:k] if scores[j] >= MIN_SCORE]
    return [items[i] for i in best]


# ---------------- 5 and 6. build the prompt, generate, check citations
def answer(question, items, vectors, audience):
    sources = retrieve(question, items, vectors, audience)
    if not sources:
        return "I couldn't find that in TrainCrest's documents.", []
    blocks = "\n\n".join(f'<source id="{n}">\n{s["text"]}\n</source>' for n, s in enumerate(sources, 1))
    system = ("Answer using ONLY the numbered sources. After each fact, cite its source number like [1]. "
              f"If the sources don't answer the question, reply exactly {NOT_FOUND}. Answer in the question's language.")
    reply = get_client().chat.completions.create(model=CHAT_MODEL, temperature=0, messages=[
        {"role": "system", "content": system},
        {"role": "user", "content": f"<sources>\n{blocks}\n</sources>\n\nQuestion: {question}"}]).choices[0].message.content
    if NOT_FOUND in reply:
        return "I couldn't find that in TrainCrest's documents.", []
    cited = sorted({int(n) for n in re.findall(r"\[(\d+)\]", reply) if 1 <= int(n) <= len(sources)})
    reply = re.sub(r"\[(\d+)\]", lambda m: m.group(0) if int(m.group(1)) in cited else "", reply)  # drop invented ones
    return reply.strip(), [(n, sources[n - 1]) for n in cited]


if __name__ == "__main__":
    audience = ("public", "staff") if "--staff" in sys.argv else ("public",)
    items, vectors = load_index()
    print(f"TrainCrest knowledge assistant ({'staff' if len(audience) == 2 else 'learner'} view). Empty line to quit.\n")
    while question := input("Question: ").strip():
        text, cited = answer(question, items, vectors, audience)
        print(text)
        for n, s in cited:
            print(f"  [{n}] {s['title']} ({s['source']})")
        print()
  2. Follow the numbered stages in the comments, which match the RAG architecture from Module 06:
    1. Ingest: read_document() turns markdown, text and CSV into one shape.
    2. Chunk: one chunk per section, with the document title on every chunk and the introduction kept.
    3. Embed and store: every chunk once, saved to data/kb_index.json with its source and audience (public or staff).
    4. Retrieve: only chunks the current audience may see, only above a relevance floor of 0.55.
    5. Prompt: numbered <source> blocks, rules to answer only from them and cite like [1], and a NOT_FOUND way out.
    6. Generate and check: citations to sources that weren't sent are removed, and the cited sources are listed.

Task 4: Judge the answers

  1. For each answer, open the cited file and check the fact is really there. Citations make answers checkable; they don't make them correct.
  2. "What is the capital of France?" should give "I couldn't find that": either no section passed the relevance floor (no model call at all) or the model replied NOT_FOUND.

Exercise 2 · An agent that asks before it acts

Module 07's hands-on exercise: an agent that understands a user request, selects and calls an appropriate tool, processes the result and returns a final response.

Task 1: Choose the agent model

  1. Agents need a model that's good at multi-step tool use. If you pulled qwen2.5:7b, set AGENT_MODEL=qwen2.5:7b in .env. Otherwise the agent uses llama3.2; it works, but expect more mistakes, and treat them as part of the lesson.

Task 2: Build the agent

  1. Create l3_agent.py: 
    """Lab 3, Exercise 2: an agent that understands a request, selects and calls tools, processes the
results and returns a final answer. Changes need the learner's approval (you type y or n).
Run:  python l3_agent.py "Please extend my AI-102 lab and tell me the new end date." """
import json
import sys
from datetime import date, timedelta

from client import AGENT_MODEL, get_client

TODAY = date.today()
LEARNER = "Mei"                                       # the signed-in learner: set by the app, not the model
ENROLMENTS = {"TC-10293": {"course": "AI-102: Azure AI Engineer", "lab_until": TODAY + timedelta(days=4),
                           "free_extension_used": False},
              "TC-10477": {"course": "Building RAG Applications", "lab_until": None, "free_extension_used": False}}
AUDIT_LOG = []                                        # every real change, in order


# ---------------- tools: two reads, one write
def my_enrolments():
    return [{"enrolment_id": k, "course": v["course"]} for k, v in ENROLMENTS.items()]


def lab_status(enrolment_id):
    e = ENROLMENTS.get(enrolment_id)
    if e is None:
        return {"error": f"{enrolment_id} is not one of {LEARNER}'s enrolments; call my_enrolments yourself"}
    if e["lab_until"] is None:
        return {"enrolment_id": enrolment_id, "lab": "not started yet"}
    return {"enrolment_id": enrolment_id, "lab_until": e["lab_until"].isoformat(),
            "free_extension_available": not e["free_extension_used"]}


def extend_lab(enrolment_id):
    e = ENROLMENTS.get(enrolment_id)
    if e is None or e["lab_until"] is None or e["free_extension_used"]:
        return {"error": "no free extension available for this enrolment; offer a support ticket"}
    e["lab_until"] += timedelta(days=7)
    e["free_extension_used"] = True
    AUDIT_LOG.append({"action": "extend_lab", "enrolment_id": enrolment_id, "lab_until": e["lab_until"].isoformat()})
    return {"enrolment_id": enrolment_id, "lab_until": e["lab_until"].isoformat(), "fee_usd": 0}


FUNCTIONS = {"my_enrolments": my_enrolments, "lab_status": lab_status, "extend_lab": extend_lab}
NEEDS_APPROVAL = {"extend_lab"}


def tool(name, description, properties=None):
    params = {"type": "object", "properties": properties or {}, "required": list(properties or {})}
    return {"type": "function", "function": {"name": name, "description": description, "parameters": params}}


ID = {"enrolment_id": {"type": "string", "description": "Like TC-12345, from my_enrolments"}}
TOOLS = [tool("my_enrolments", "List the signed-in learner's enrolments with their IDs."),
         tool("lab_status", "Lab end date for one enrolment and whether the free extension is available.", ID),
         tool("extend_lab", "Use the free 7-day lab extension. Changes the booking; the learner must approve.", ID)]
SYSTEM = (f"You are Traincrest Assist acting for the signed-in learner, {LEARNER}. Today is {TODAY}. "
          "Use tools for every fact and action; never guess IDs or dates. The learner can't call tools; "
          "call them yourself, starting with my_enrolments. If an action is declined, don't retry it. "
          "Finish with a short answer saying what was done.")


def approve(name, args):
    """A person decides. The preview comes from the real data, not from the model."""
    status = lab_status(args.get("enrolment_id", ""))
    print(f"\n  APPROVAL NEEDED: extend {args.get('enrolment_id')} by 7 days, free "
          f"(lab currently open until {status.get('lab_until')})")
    return input("  Approve? [y/n] ").strip().lower() == "y"


def run(request, max_steps=8):
    client = get_client()
    messages = [{"role": "system", "content": SYSTEM}, {"role": "user", "content": request}]
    for step in range(1, max_steps + 1):                      # 1 understand the task
        msg = client.chat.completions.create(model=AGENT_MODEL, messages=messages, tools=TOOLS).choices[0].message
        if not msg.tool_calls:                                # 5 final response
            return msg.content.strip()
        messages.append(msg)
        for call in msg.tool_calls:                           # 2 select a tool
            name, args = call.function.name, json.loads(call.function.arguments or "{}")
            if name in NEEDS_APPROVAL and not approve(name, args):
                result = {"error": "the learner declined this action"}
            elif name in FUNCTIONS:
                try:
                    result = FUNCTIONS[name](**args)          # 3 execute the tool
                except TypeError as e:
                    result = {"error": f"bad arguments: {e}"}
            else:
                result = {"error": f"unknown tool {name}"}
            print(f"  step {step}: {name}({args}) -> {json.dumps(result)}")
            messages.append({"role": "tool", "tool_call_id": call.id, "content": json.dumps(result)})
            # 4 the result goes back to the model, which evaluates it and decides the next step
    return "Sorry, that needed more steps than I'm allowed."


if __name__ == "__main__":
    request = sys.argv[1] if len(sys.argv) > 1 else "Please extend my AI-102 lab and tell me the new end date."
    print(f"Request: {request}  (agent model: {AGENT_MODEL})")
    print(f"\nAnswer: {run(request)}")
    print(f"Audit log (what really changed): {AUDIT_LOG or 'nothing'}")
  2. Find the five steps of the agent flow in run(): (1) understand the task (the model reads the request), (2) select a tool, (3) execute it, (4) evaluate the result (it goes back to the model, which decides the next step), (5) return a final response.
  3. Find the guard rails: LEARNER is set by the app; NEEDS_APPROVAL makes extend_lab stop for a person, with a preview computed from real data; max_steps stops runaway loops; AUDIT_LOG records what really changed.

Task 4: Push it

  1. Ask for something it can't do: python l3_agent.py "Extend the lab for my RAG course." (that course hasn't started, so there's no lab yet). Does the agent explain the tool's error, or claim success?
  2. Ask a question that needs no change: python l3_agent.py "When does my AI-102 lab close?". No approval should be requested.
Checkpoint

Your agent finds the right enrolment by itself, asks before extending the lab, does nothing when you decline, and its audit log matches what actually happened.

Troubleshooting

SymptomFix
The knowledge assistant says "couldn't find" for everythingThe relevance floor (0.55) is for nomic-embed-text. With another embedding model, lower MIN_SCORE; delete data/kb_index.json after changing the model.
Answers have no [1] citationsSmall models often skip them. The answer may still be right; use a larger model for reliable citations.
The agent asks you to look up your enrolmentsA weak-model habit. Use qwen2.5:7b, or strengthen the system prompt ("never ask the learner to call tools").
The agent guesses an ID like TC-12345The tool refuses it and tells the model to call my_enrolments; good models recover on the next step.
Each agent step takes a minuteNormal for a 7B model on a CPU; the agent makes 3 to 5 calls. Close other apps, or use Lab 0's Option B for AGENT_MODEL.

Review and cleanup

  • RAG answers come from retrieved documents, with citations you can check and a way to say "not found".
  • Permission filters belong inside retrieval: learners never see staff documents.
  • An agent is a loop: understand, select a tool, execute, evaluate, answer, within a step budget.
  • Changes need a human's approval of an effect computed by code, and the audit log, not the model's words, says what happened.

Cleanup: delete data/kb_index.json and data/search_index.json if you want the disk space back (they're rebuilt when needed). To remove a model: ollama rm qwen2.5:7b.
